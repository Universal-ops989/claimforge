# ClaimForge UI

The ClaimForge design system: accessible, themeable React components for the
ClaimForge claims platform.

- **Accessible by default.** Every story runs automated axe checks (see the
  _Accessibility_ panel).
- **Themeable with tokens.** Colors, spacing and typography are CSS custom properties.
- **Composable.** Components forward refs and accept native element props.

Browse components in the sidebar. Each page documents props, variants and usage
guidance.
